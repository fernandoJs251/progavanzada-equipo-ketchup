BikerStock3D - Sistema de Gestión y Catálogo para Tienda de Cascos

Descripción General del Proyecto
**BikerStock3D** es una solución de software diseñada y desarrollada para optimizar el control de inventarios, la administración de productos y el flujo de ventas en una tienda especializada en cascos y accesorios para motociclistas. El sistema busca automatizar el registro de entradas y salidas de stock, facilitar la búsqueda de modelos específicos según las necesidades de seguridad del cliente y ofrecer una interfaz intuitiva tanto para los administradores como para los usuarios finales.

---

Objetivos del Sistema

### Objetivo General
Desarrollar e implementar una plataforma web integral (**BikerStock3D**) que centralice y automatice la gestión de inventario, la catalogación de productos y la administración de ventas para una tienda especializada en cascos de motociclista, optimizando los tiempos de atención y garantizando un control preciso del stock.

### Objetivos Específicos
* **Gestión y Control Detallado de Inventario:**
  * Automatizar el registro de entradas, salidas y actualizaciones de cascos en tiempo real.
  * Clasificar el catálogo según atributos técnicos clave: marcas, modelos, tallas (XS a XXL), colores, tipos de visor y certificaciones de seguridad (DOT, ECE 22.05 / 22.06, SNELL).
  * Generar alertas automáticas de stock mínimo para evitar el desabastecimiento de los modelos más solicitados.

* **Administración de Ventas y Clientes:**
  * Facilitar la creación y registro de órdenes de compra de forma rápida e intuitiva.
  * Mantener un historial detallado de transacciones y pedidos realizados por los clientes.
  * Permitir la búsqueda y filtrado avanzado de productos según el presupuesto y nivel de protección requerido por el motociclista.

* **Seguridad y Control de Accesos:**
  * Implementar un sistema de autenticación de usuarios con roles diferenciados (Administrador y Cliente/Vendedor).
  * Garantizar la integridad y confidencialidad de los datos mediante la gestión segura de permisos en el sistema.

* **Arquitectura Escalable y Eficiente:**
  * Construir una arquitectura modular y limpia utilizando **Python con Flask y SQLAlchemy** en el backend para un manejo ágil de la base de datos relacional.
  * Garantizar la facilidad de mantenimiento y la integración futura con módulos de pasarelas de pago o aplicaciones móviles.
